# SentinelAI

**Explainable AI-Based Hybrid Intrusion Detection and SOC Alert Correlation System**

## Overview

SentinelAI is a cybersecurity platform that analyzes network traffic and detects threats using:

- Rule-based detection
- Machine learning anomaly detection
- Event correlation
- Dynamic risk scoring
- MITRE ATT&CK mapping
- Explainable AI

## Project Status

🚧 Under development — Building layer by layer

## Quick Start

```bash
# 1. Create virtual environment
python -m venv venv

# 2. Activate it (Windows)
venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the application
python main.py
```
